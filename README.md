# ADF lets learn

## What is ADF

ADF usually means Azure Data Factory — a cloud ETL and data-integration service on Microsoft Azure. It lets you build pipelines that move, transform, and schedule data across on-premises and cloud sources. Key concepts: Linked Services (connections), Datasets (data shapes), Pipelines (orchestration), Activities (tasks), Integration Runtimes (execution), Mapping Data Flows (visual transforms), and Triggers (scheduling). Common uses: ETL/ELT, data ingestion, hybrid data movement, and orchestration for analytics/BI workloads.
